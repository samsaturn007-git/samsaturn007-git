## Banner prompt

Use case: stylized-concept. Asset type: backplate for Samuel Dsouza’s GitHub profile banner, intended for a layout with live typeset copy over the LEFT. Create a high-end editorial 3D render with a sculptural exploded stack of three dark translucent graphite circuit boards suspended above a fine blueprint grid. Central bright yet refined ice-cyan light traces through the boards, with restrained amber pinpoints. One coherent stack with clearly readable silhouette and beautiful material detail. Deep ink navy #091523 background. Wide landscape with the entire subject strictly between 63% and 92% of the image width, vertically centered, sized to fit inside the central 65% of the height so I can crop the top and bottom to a banner. The LEFT 57% is nearly uniform deep ink navy, dark and empty so overlaid white typography reads. Professional hardware design studio, selective depth of field, restrained modern lighting, tasteful contrast. No text, logos, letters, digits, glyphs, people, watermark, or interface chrome.
